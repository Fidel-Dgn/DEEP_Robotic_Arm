# DEEP_Robotic_Arm
Ce dépôt contient le développement complet d’un bras robotique autonome basé sur un microcontrôleur STM32G431 et la DEEP Purple Complete Board. Le système est conçu pour détecter, saisir, trier et déplacer des objets grâce à une combinaison de capteurs, de servomoteurs et d’algorithmes embarqués.
